# cat-in-a-labyrinth
Hello, this is my hackathon project, where I created a labyrinth in which a cat tries to escape. You play as a cat and collect treasures. In the labyrinth are also hidden some abilities that may help the player with getting around ghosts. 

How to start the game: 

You will need (see requirements):
  Python
  Pygame
  
1. Open your favorite Python interpreter.
2. Make sure that all the files are at the same level (for VS Code).
3. Download requirements.
4. Run the bludiste.py file.


Source of graphics: https://opengameart.org/content/denzis-public-domain-art
